# 本地驱动库 · drivers

把从厂商官网下载到的驱动安装包**直接丢进这个文件夹**，然后双击
`tools\索引本地驱动.bat`，应用里对应机型就会变成 **「立即下载」**（真·本地直下，不走网页）。

## 命名建议（决定能不能自动匹配）

文件名里**带上完整型号**即可，空格/横杠/下划线都能自动忽略：

```
HP_LaserJet_1020_FullSolution.exe          ✔ 匹配 LaserJet 1020
HP LaserJet Pro M404dn 驱动.exe            ✔ 匹配 LaserJet Pro M404dn
Canon_PIXMA_G3020_Win11.exe                ✔ 匹配 PIXMA G3020
Epson L3251 驱动.zip                       ✔ 匹配 L3251
Brother HL-L2360DW.exe                     ✔ 匹配 HL-L2360DW
HP 1020驱动.exe                            ✔ 也能匹配（型号在文件名里）
driver_2024_v3.exe                         ✘ 匹配不到
```

规则：程序会把文件名去掉扩展名、去掉空格和符号后，查找是否包含某个机型的完整型号。
**带品牌名的型号优先**（避免 `1020` 这种短号误匹配）。

## 不想用脚本？

打开应用 → 右上角 **「驱动库」** → **「选择文件夹」**，直接选中这个 `drivers` 目录，
当次会话内同样生效（刷新页面后需重新选一次，或跑一次索引脚本固化）。

## 支持的安装包格式

`.exe` `.zip` `.rar` `.7z` `.msi` `.cab` `.dmg` `.pkg` `.bin`

## 说明

- 本目录只放**你自己下载的安装包**，本工具不内置任何厂商驱动文件。
- 安装包体积较大时建议按品牌建子文件夹，扫描会递归读取。
